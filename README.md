# 🖼️ WebP Converter Pro

**WebP Converter Pro** is a high-performance, modern batch image conversion desktop app built to convert your images into optimized **WebP** format with maximum efficiency and quality control.

---

## ✨ Features

- **⚡ Fast Batch Conversion**: Convert individual files or entire folders simultaneously.
- **📁 Multi-Format Support**: Supports `PNG`, `JPG`, `JPEG`, `AVIF`, `BMP`, `TIFF`, `GIF`, and `ICO`.
- **🎛️ Custom Quality Controls**: Adjustable compression slider (1% – 100%) or **Lossless WebP Mode** for 100% pixel accuracy.
- **📍 Real-Time Output Path Preview**: View the exact output file destination path for each image in the UI before converting.
- **🖱️ Drag & Drop Support**: Drag images or folders directly into the app window.
- **📂 Flexible Output Folder**: Save converted WebP images in the same folder as the original images or select a custom output directory.

---

## 🚀 How to Install and Run (Portable Executable)

No installation or admin permissions required!

1. **Download the Zip Package**:
   - Download `WebPConverterPro_Portable.zip` from the release folder (`dist/WebPConverterPro_Portable.zip`).

2. **Extract the Files**:
   - Right-click `WebPConverterPro_Portable.zip` and select **Extract All...** to extract it to any folder on your computer (e.g., Desktop or Downloads).

3. **Launch the App**:
   - Open the extracted folder and double-click **`WebPConverterPro.exe`**.
   - *Tip: Right-click `WebPConverterPro.exe` and select **Pin to Taskbar** or **Create Shortcut** for easy access.*

---

## 📖 How to Use

1. **Add Images**:
   - Click **📂 Files** to pick images, **📁 Folder** to select an entire folder, or simply **Drag & Drop** images into the app window.
2. **Configure Settings**:
   - Adjust the **Quality Slider** (e.g., 80%) or check **Lossless WebP Mode**.
3. **Set Destination (Optional)**:
   - By default, converted images are saved in the same directory as the source file. Click **Choose** under **Destination Folder** if you want to output all files to a specific folder.
4. **Convert**:
   - Click **⚡ Convert** on a specific file row, or click **🚀 Start Conversion** to convert all selected files at once.
5. **Access Output**:
   - Click **Open Folder** in the sidebar to open the output directory.

## 💻 Running from Source Code (Developers)

### Prerequisites
- Python 3.10+ installed on your system.

### Steps
1. Clone or download the repository code.
2. Install required Python packages:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the application:
   ```bash
   python app.py
   ```
